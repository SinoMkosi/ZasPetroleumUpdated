# ZAS Petroleum – Vehicle Service & Booking System

## Project Overview

This repository contains the *interactive prototype (wireframes)* for the ZAS Petroleum Vehicle Service & Booking System, developed as part of the Work Integrated Learning (WIL) module – *XISD5319*.

The prototype demonstrates the core user interfaces for the system, including:
- Customer Login & Registration
- Customer Dashboard
- Book a Service (with date/time slot selection)
- My Bookings (view and cancel appointments)

The system is designed to modernise ZAS Petroleum's vehicle service management by replacing manual phone bookings and paper logbooks with a digital, efficient, and user-friendly platform.
